# 游戏音频放置说明

请使用下方固定文件名。游戏接入时会直接读取这些路径，因此不要使用空格、中文名或额外编号。

## 背景音乐

将背景音乐放入 `bgm/`：

- `bakery-loop.mp3` — 烘焙店循环背景音乐，建议无缝循环、80 BPM、无歌词。

## 音效

将音效放入 `sfx/`：

- `reveal.mp3` — 翻开格子
- `flag.mp3` — 贴上或收回小顾贴纸
- `help.mp3` — 339 扫描或提示
- `win.mp3` — 游戏胜利
- `lose.mp3` — 踩中烤焦面包、游戏失败
- `click.mp3` — 普通按钮点击

## 推荐导出规格

- 格式：MP3
- 采样率：44.1 kHz
- 码率：128–192 kbps
- 音效开头与结尾不要保留长时间静音
- 文件扩展名请保持小写 `.mp3`
